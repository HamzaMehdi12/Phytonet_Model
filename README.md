# 🍅 HighPhytoSparseNet: A Lightweight Multi-Head Object Detection Model for Edge-Based Agricultural Applications

> **PhytoNetEdge** achieves **65.1% mAP@0.5** and **36.7% mAP@0.5:0.95** with only **3.8M parameters and 0.5 GFLOPs**, outperforming YOLOv8n (+12.8 pts), YOLOv5n (+19.4 pts), and YOLOv5s (+6.9 pts) while using **17x less compute** than YOLOv8n.
